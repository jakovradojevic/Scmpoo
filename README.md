# STRAY SHEEP The Screen Mate (Scmpoo)

![Alien sheep banner](docs/images/alien_banner.png)

_STRAY SHEEP The Screen Mate_ (Japanese: STRAY SHEEP スクリーンメイト) is a [digital pet](https://en.wikipedia.org/wiki/Digital_pet) / Windows **screen mate** based on Fuji TV's multimedia project _STRAY SHEEP_ (Japanese: ストレイシープ). The application includes character animations from Fuji TV's late-night series _The Adventure of STRAY SHEEP_ (1994), featuring Poe, Merry, and the alien Hue.

This repository is based on the C reconstruction in [lwu309/Scmpoo](https://github.com/lwu309/Scmpoo), which recovers the original 16-bit New Executable for modern 32/64-bit Windows. This fork adds an English UI translation and an alien sheep mode.

Compiled executables for the upstream project are on its [Releases](https://github.com/lwu309/Scmpoo/releases) page.

---

## Alien sheep mode — recreated from memory

Some older / alternate builds of Scmpoo were remembered as having a rarer “alien” Poe: **green horns**, **red eyes**, a distinct UFO abduction, then an aggressive spell on the desktop. The publicly recovered EXE only shipped the normal purple-horn sheep sheets — that alien look was not in the bitmaps.

This fork rebuilds that remembered behaviour **from memory and reverse-engineering of the existing screen mate**, not from a dumped alien-mode binary:

1. **Sprites** — every locomotion sheet (`101`–`111`) is recolored into `112`–`122` (green horns + red pupils), generated by `tools/generate_alien_sheep_bmp.py`.
2. **Sequence** — red UFO beam abduction → sheep falls back with gravity → brief landing pose → temporary alien overlay on the **normal** AI (walk, climb, windows, taskbar, drag).
3. **Aggression** — while alien, Poe chases other instances faster, knocks them into a roll, and they sometimes panic-flee.
4. **Rarity** — alien abduction is wired into the same special-action table as the other UFO events, so it stays uncommon.

### Trying alien mode

- Let special actions fire naturally (same rarity class as other UFO scenes), or  
- **Ctrl+Shift+double-click** Poe → debug dialog → **Alien**.

Run several instances to see chase / knock / flee against normal sheep.

## Usage

Poe appears on the desktop and usually picks run or walk. Some actions play his voice. Special actions (including UFOs and alien abduction) are rarer and only when a single instance is free to take them.

He reacts to visible windows (collisions, landing on top edges when gravity is on). Up to 9 instances can run at once; they can bump into each other.

- **Drag** with left/right mouse to move him.
- **Drop a file** on him to “eat” it (`.wav` plays).
- **Left double-click** — settings (needs admin on Vista+ to write the `.ini` under the Windows directory).
- **Right double-click** — exit.
- **Ctrl+Shift+left double-click** — debug action picker.

## Build from source

CMake ≥ 3.16. Generate Visual Studio projects or MinGW Makefiles, then build the `Scmpoo` target.

```bash
cmake -S . -B cmake-build-debug
cmake --build cmake-build-debug
```
